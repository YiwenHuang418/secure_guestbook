# Secure Guestbook

一个基于 Python 标准库和 SQLite 实现的安全留言板学习项目，用于实践 Web 常见漏洞的防御方法。

## 项目功能

- 发布、存储和展示留言
- 使用 SQLite 持久化保存数据
- 上传 TXT 文本附件
- 自动生成随机文件名并展示附件列表

## 安全防护

- **XSS 防护**：使用 `html.escape()` 对留言内容和用户名进行 HTML 输出转义。
- **CSRF 防护**：使用随机 CSRF Token，对留言提交和文件上传请求进行验证。
- **文件大小限制**：限制上传请求体不超过 1 MB，超限返回 HTTP 413。
- **文件类型检查**：检查 `.txt` 扩展名及 UTF-8 解码情况，不符合要求返回 HTTP 415。
- **路径安全**：使用服务器生成的随机文件名，避免直接信任用户提供的保存路径。
- **文件防覆盖**：使用 `xb` 模式创建文件，避免覆盖已有附件。

## 运行方法

环境：Python 3，使用标准库，无须额外安装第三方依赖。

首先初始化数据库：

```bash
python init_db.py
```

然后启动服务器：

```bash
python server.py
```

浏览器访问：

http://127.0.0.1:8001/

## 测试结果

已完成正常留言、存储型 XSS、CSRF Token 缺失、正常文件上传、错误文件扩展名及超大文件上传等测试，核心功能符合预期。

## 已知问题与局限

- 超大文件上传时观察到三个 HTTP 413 响应，具体原因尚未定位。
- CSRF Token 使用单会话教学模型，尚未实现真正的用户登录与 Session 绑定。
- 文件类型验证较为基础，不能保证所有可解码为 UTF-8 的文件都是安全文本。
- 项目仅用于本地安全学习，不适合直接部署到公网。
